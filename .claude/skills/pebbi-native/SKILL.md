# pebbi-native

Native scope: the first-launch form, versioned Keychain profile, local validation, save/load/edit/reset and error recovery. Build nothing until explicitly authorized. Follow BYOK-001 through BYOK-012; no hosted account, database, billing or full agent runtime.
