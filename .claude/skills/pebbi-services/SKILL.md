# pebbi-services

Compatibility name: services means direct Azure client boundaries, NOT a hosted Pebbi service. Specify/verify HTTPS endpoint and API-family validation, exact deployment identity, Keychain-only secrets, explicit destination and no network during local Save. No Supabase, Render, Vercel, Entra application account, Stripe or server credentials. Later live modality tests require separate consent and actual evidence.

Read [AGENTS.md](../../../AGENTS.md), [the current feature](../../../docs/product/LOCAL-AZURE-ONBOARDING.md), [current contract](../../../docs/CONTRACT.md), and [future build prompt](../../../docs/agents/BUILD-PROMPT.md). The owner currently requests docs/repository changes only.
